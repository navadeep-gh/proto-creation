# Nexus Prototype v2.0 - Interactive UX Sandbox

An advanced, interactive web application prototype engineered to simulate real-world dashboard navigation, state architecture management, and user telemetry loops. This project satisfies the core requirements of **Task 3: Interactive Prototype Creation**.

## 🚀 Live Demo Structure

The architecture is split into clean, modular files to provide clear separation of concerns, ensuring an accurate language breakdown statistics report on GitHub:

* `index.html` - Semantic wireframe skeleton layout.
* `style.css` - Visual layer hierarchy, responsive dark-mode variables, and transition keyframes.
* `app.js` - Client-side view routing, real-time dataset filters, and state pipelines.

---

## 🛠️ Tech Stack & Language Breakdown

### 1. Structure (HTML5)
* Provides semantic application layout templates (`<aside>`, `<main>`, `<header>`).
* Utilizes HTML5 `<canvas>` API objects to render custom micro-interaction telemetry maps.

### 2. Design & Motion (CSS3)
* **Grid & Flexbox Modules:** Powers a fluid, adaptive interface array.
* **CSS Custom Properties (Variables):** Standardizes the application interface styling guide (`--primary`, `--surface-accent`).
* **Micro-interactions:** Smooth animations (`@keyframes stageEnter`) mimic native mobile and web application panel switches.

### 3. Logic & State Management (JavaScript ES6+)
* **Single Page Application (SPA) Router:** Switches layout views instantly without refreshing the browser.
* **Query Filtering Engine:** Executes real-time string token matching against UI card attributes.
* **Dynamic Data Pipelines:** Updates counter states and appends user-testing log objects directly to the screen view in real time.
